# SimpleAI2026

本地优先、可离线的 **Simple 系列** 开源工具。尽量在浏览器或本机完成，少依赖服务器。

## Projects

| 项目 | 简介 |
|---|---|
| [SimpleBase](https://github.com/SimpleAI2026/SimpleBase) | Serverless SQLite / 简化云数据库使用（Go） |
| [SimpleMind](https://github.com/SimpleAI2026/SimpleMind) | AI 思维导图：归纳、第一性原理等 |
| [SimpleExcalidraw](https://github.com/SimpleAI2026/SimpleExcalidraw) | Excalidraw 中文版，支持 AI 生成与动画 |
| [SimpleTools](https://github.com/SimpleAI2026/SimpleTools) | 纯前端离线开发者工具箱（Vue 3，Chrome / VS Code 插件） |
| [SimpleCode](https://github.com/SimpleAI2026/SimpleCode) | 浏览器内 Wasm 代码运行器与教程 |
| [SimpleAgent](https://github.com/SimpleAI2026/SimpleAgent) | 自我进化的 Agent |

## Principles

- **Local-first**：能在本地算的，不上云
- **Simple**：小而专注，拿来即用
- **Open**：代码与文档公开，方便二次开发
